# CVCRAFT

**CVCRAFT** is a web application designed for building, customizing, and exporting ATS-friendly resumes effortlessly. It allows users to create clean, professional CV templates and export them seamlessly to PDF format.

---

## 🚀 Features

* **Real-Time CV Builder:** Fill in personal information, summary, experience, and education with immediate live visual feedback.
* **Customization:** Tailor layouts and styling for modern, clean resume presentations.
* **ATS-Friendly Outputs:** Optimized layouts to help pass Automated Applicant Tracking Systems.
* **Direct PDF Export:** Clean, single-page print and PDF generation.
* **Responsive Dashboard:** Simple, intuitive web interface for fast editing.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **PDF Rendering:** CSS Print Media Queries / Client-side PDF generation
